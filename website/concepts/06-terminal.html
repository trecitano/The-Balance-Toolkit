A balance board in your stdout

Pair a Wii Balance Board, run an activity and stream centre of pressure from the terminal with tbt, or use the desktop app. Same core, same files.

Watch the packet change

  
Every sample goes out on TCP port 11223 as 40 big-endian bytes, >qQ6f. Lean on the board and the bytes that change light up.

  

    

    

      

      

    

  






  
Every command

  

    
tbt
Opens the interactive dashboard: boards, recording, replay and settings in one screen.

    
tbt devices scan
Pair new boards. Press the red SYNC button inside the battery compartment.

    
tbt devices tare
Zero a connected board’s sensors, with nothing on the board.

    
tbt devices identify
Blink a board’s LED for about ten seconds to tell boards apart.

    
tbt session run
Record until Ctrl-C, until the activity ends, or until --duration elapses.

    
tbt replay
Replay a recorded session through the processing pipeline and streams.

    
tbt activities list
List the posturography activity templates.

    
tbt settings path
Print where the toolkit keeps its data, shared with the desktop app.

Read the TCP stream in Python
sock = socket.create_connection(("::1", 11223))
while True:
    t, mac, tr, br, tl, bl, x, y = \
        struct.unpack(">qQ6f", sock.recv(40))
